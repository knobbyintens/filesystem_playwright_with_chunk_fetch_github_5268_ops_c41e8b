# Meridian Metropolitan Transit - Operations Repository

This repository holds operational reference data and work-order records for the
Copper Line weekend possession exercise.

## Contents

- `docs/network-map.html` - geographic system schematic and station directory.
- `data/line-controller-export.json` - line controller route register export (authoritative
  station codes, sequence numbers, previous/next pointers and interchanges).
- `docs/plan-schema.json` - structure of the possession plan deliverable.
- Issues - work-order requests for the possession weekend.

The schematic is illustrative only. Operational station sequences must be taken
from the route register export.
