# People Operations

This repository publishes profile pages for Cascade Labs staff.

## Layout

- `team/research/` - research-track profiles
- `team/engineering/` - platform and engineering-track profiles
- `templates/profile-template.md` - canonical profile structure
- `docs/style-guide.md` - house editorial rules

## Workflow

Profiles are drafted from the authoritative People Directory and published after onboarding.
Keep the team roster in `team/README.md` in sync whenever a profile is added.
